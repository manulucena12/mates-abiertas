## Sobre el proyecto

**Matemáticas Abiertas** es un curso de matemáticas completamente abierto y gratuito.

El objetivo no es simplemente aprender a resolver ejercicios, sino **entender las ideas que hay detrás de las matemáticas**.

Este proyecto está inspirado en <a href="https://fullstackopen.com/en/">Full Stack Open</a>, creado por la universidad de Helsinki con el objetivo de ayudar a personas de todo el mundo. 

La idea es construir las matemáticas desde sus fundamentos y mostrar cómo unos conceptos surgen naturalmente a partir de otros con el fin principal de fomentar el pensamiento crítico y no la mecanización de las matemáticas.


## Contenido

## Desarrollo

El equipo de desarrollo ha usado herramientas open source para crear el proyecto

- Lenguaje de programación: <a href="https://github.com/microsoft/typescript">TypeScript</a>
- Frontend Framework: <a href="https://github.com/react/react">React</a>
- AI Harness: <a href="https://github.com/anomalyco/opencode">Opencode</a>
- AI Model: <a href="https://huggingface.co/deepseek-ai">DeepSeek</a>
- Typescript Runtime: <a href="https://github.com/oven-sh/bun">Bun</a>
- Versioning System: <a href="https://github.com/git/git">Git</a>

Para instalar el proyecto, tienes que usar estos tres comandos

```sh
git clone git@github.com:manulucena12/mates-abiertas.git
cd mates-abiertas
bun install
```
