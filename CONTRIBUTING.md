# Contribuir a Matemáticas Abiertas

Te damos las gracias por animarte a contribuir en Matemáticas Abiertas.

Para poder añadir un cambio, crea una **Issue** si es simplemente una propuesta, o un **Pull Request** si quieres implementar el cambio directamente.

Puedes editar el contenido de los módulos para corregir errores o realizar cambios en el propio código, pero no podrás crear módulos nuevos.

Si tienes alguna duda, contacta por email a [mlucenasalas@gmail.com](mailto:mlucenasalas@gmail.com).
